# Just-Enough-Tooltips
# EN:

JETT is a client-side only mod for customizing item tooltips.

## Features
- Hide attribute modifiers individually by type.
- Merge multiple modifiers of the same attribute into a single line.
- Add custom tooltip text to any item.
- Toggle equipment slot headers per slot.
- Fine-grained control via item whitelist.
  
All features are opt-in and disabled by default.

# 中文:

JETT 是一个仅客户端模组，用于修改物品的悬浮提示。

## 模组功能
- 按类型单独隐藏属性修饰符。
- 合并多行的同种属性修饰符。
- 为任意物品添加自定义悬浮提示文字。
- 逐槽位开关装备标题行。
- 物品白名单精细控制。

功能全部可选，并且默认配置均为未启用。
